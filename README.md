# Sublevel 09 — Beta 0.1.0-beta.1

An early Windows horror exploration beta, ready for community testing.

## Download and play
- Download `Sublevel09-0.1.0-beta.1-Windows-x64.zip` from this release's assets.
- Extract the entire ZIP, then run `Sublevel09.exe` inside the extracted folder.
- No Unity installation required. Windows 64-bit only.
- Keep all included files together; do not download only the executable.

## Controls
WASD: move · Mouse: look · Hold R / Left Shift: run · F: flashlight · E: interact · Escape: pause · O: settings · Alt+F4: quit.

## Tester feedback
Please report bugs with the game version, Windows version, PC specs, room/location, reproduction steps, and screenshots or video when possible. FPS/resolution reports are welcome. Mark puzzle spoilers clearly.

## Beta notes
- Includes the main hall, morgue, pump room, and electrical room.
- Contains horror imagery, blood, pursuit, darkness, and sudden scares.
- Unsigned early beta: Windows may show an unfamiliar-publisher warning. Use only the creator's trusted download; do not disable security software.
- Build succeeded and standalone startup was smoke-tested through process/log checks. Full standalone playthrough and compatibility across other PCs remain to be tested.
